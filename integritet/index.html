Det här samlar vi inte in

Webbplatsen använder inga kakor, ingen besöksmätning och inga formulär. Den hämtar inget innehåll från andra tjänster. Därför får ingen annan veta genom sidan att du besöker den.

Värden loggar din IP-adress

Webbplatsen ligger hos GitHub (GitHub, Inc., USA). När du besöker den loggar och sparar GitHub din IP-adress av säkerhetsskäl. GitHub hanterar uppgiften enligt sin egen integritetspolicy.

GitHub kan föra över uppgifter till USA. Enligt GitHub sker det med EU-kommissionens standardavtalsklausuler och inom ramen för EU-U.S. Data Privacy Framework. GitHubs integritetspolicy

Om du kontaktar oss

Om du skriver till oss behandlar vi ditt namn, din e-postadress och det du skriver, för att kunna svara. Den rättsliga grunden är vårt berättigade intresse av att kunna besvara frågor.

Vi sparar uppgifterna medan frågan pågår och högst tolv månader därefter, om de inte behövs längre för ett avtal som följer av kontakten eller för att lagen kräver det.

Skriv inga uppgifter om andra personer, inga klientuppgifter och inga känsliga uppgifter i ditt meddelande.

Dina rättigheter

Du har rätt att få veta vilka uppgifter vi har om dig, få felaktiga uppgifter rättade och få uppgifter raderade. Du kan också invända mot behandlingen. Kontakta oss på hej@liljasystems.com eller per post till adressen ovan.

Om du är missnöjd med hur vi hanterar dina uppgifter kan du klaga hos Integritetsskyddsmyndigheten (IMY).
